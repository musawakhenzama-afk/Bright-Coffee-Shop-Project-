A BrightLearn Data Analytics Project


📘 Overview

This project presents a comprehensive data analysis case study for Bright Coffee Shop, developed as part of the BrightLearn Data Analytics Bootcamp.
The objective is to uncover actionable business insights from transactional sales data to assist a newly appointed CEO in driving revenue growth and product performance improvements.

As a Junior Data Analyst, I analyzed historical data to identify high-performing products, peak sales periods, and overall trends — turning raw data into clear, data-driven recommendations.

🎯 Objectives

The main goals of this project were to:

Identify which products generate the most revenue

Analyze sales trends across products and time intervals

Determine the store’s best-performing time of day

Provide actionable recommendations to improve sales performance

🔍 Methodology
1. Data Planning & Architecture

Designed a Data Flow Diagram in Miro, showing data movement from ingestion to visualization.

Defined key performance metrics, such as:

Total Revenue = unit_price * transaction_qty

Units Sold by Product Category

Sales by 30-Minute Time Buckets

2. Data Processing in Snowflake

Imported raw transactional data (CSV format) into Snowflake.

Cleaned data and corrected inconsistent price formats (e.g., converting 3,1 → 3.1).

Added a time bucket column for interval-based sales grouping.

Computed total revenue and summarized data by product and time interval.

3. Data Analysis in Excel / Power BI

Created pivot tables and charts to visualize:

Total revenue by product

Peak time intervals

Best- and worst-performing items

Applied conditional formatting and interactive visuals for quick insight extraction.

4. Insights & Recommendations

Interpreted sales patterns and provided data-backed recommendations to optimize operations.

Suggested marketing and inventory strategies to enhance profitability.
